# AoE2Control API Audit v2 — catálogo de contratos Lua

**Revisão:** 2026-10-20. **Origem:** [control-api.d.lua](https://github.com/aoe2control/aoe2-control-lua-vscode-extension/blob/main/definitions/control-api.d.lua). **Contexto:** [documentação oficial versionada](https://github.com/aoe2control/aoe2control.github.io/tree/main/docs). **Escopo:** leitura, controle, automação, interface e integração; nenhuma edição de mapas.

Este é um **levantamento estático**, não teste do motor DE nem confirmação de paridade HD. As anotações são extraídas de cada bloco de documentação imediatamente adjacente à função, evitando atribuir comentários de uma API vizinha à seguinte. A presença da grafia em uma página é indício de referência textual, não de conformidade semântica. Toda API HD permanece `a_investigar_HD`.

## Cobertura

- **380** funções/métodos declarados; **213** com anotação `@param`; **303** com `@return`; **196** citados por grafia nas 16 páginas analisadas.
- Não é adequado interpretar número de assinaturas como número de funcionalidades ou como implementação comprovada no motor.
- Referências documentais são cruzadas por nome; detalhes devem ser confirmados individualmente nos exemplos e páginas relevantes.

## Política de validação

- **DE declarada:** função aparece em `control-api.d.lua`.
- **DE documentada:** função aparece nominalmente na documentação oficial.
- **DE exemplificada:** existe chamada concreta em módulo oficial; isso não demonstra exaustivamente seu comportamento.
- **HD candidata:** contrato proposto, sem teste de compatibilidade.
- **HD validada:** apenas após experimentos reprodutíveis com evidência no `AoE2HD.mapping` quando depender de memória.

## Limites metodológicos

A coluna retorno reproduz anotações sem provar retorno real. A análise estática não valida sobrecargas, erros, latência, propriedade do objeto, integridade de ponteiros, offset ou segurança de thread. Tipos e parâmetros devem ser interpretados usando [Types](https://aoe2control.github.io/types/), [Commands](https://aoe2control.github.io/commands/) e [Limits](https://aoe2control.github.io/limits/).
